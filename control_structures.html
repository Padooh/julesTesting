What are Control Structures?

Control structures are fundamental components of programming that allow you to dictate the flow of execution of your program's instructions. Instead of the computer just running code line by line from top to bottom, control structures enable you to make decisions, repeat actions, and choose different paths based on certain conditions. They are essential for creating dynamic and responsive programs.

Conditional Statements (If/Else If/Else)

Conditional statements allow a program to execute different blocks of code based on whether a specified condition is true or false. This is how programs make decisions.

Simple If Statement

The simplest form executes a block of code only if a condition is true.

Example (Pseudocode):

IF temperature > 30 THEN

  PRINT "It's a hot day!"

END IF

If/Else Statement

This executes one block of code if the condition is true and another block if it's false.

Example (Pseudocode):

IF score >= 60 THEN

  PRINT "You passed!"

ELSE

  PRINT "You failed."

END IF

If/Else If/Else Statement

This allows for checking multiple conditions in sequence. The first true condition's block is executed. If none are true, the ELSE block (if present) is executed.

Example (Pseudocode):

IF grade == "A" THEN

  PRINT "Excellent!"

ELSE IF grade == "B" THEN

  PRINT "Good job!"

ELSE IF grade == "C" THEN

  PRINT "Fair."

ELSE

  PRINT "Keep trying!"

END IF

Loops

Loops are used to repeat a block of code multiple times. This is useful for tasks like processing all items in a list or performing an action until a condition changes.

For Loops

For loops are typically used when you know in advance how many times you want to repeat the code, or when you want to iterate over each item in a sequence (like a list or array).

Example (Iterating a specific number of times - Pseudocode):

FOR i FROM 1 TO 5 DO

  PRINT "Iteration number: " + i

END FOR


Example (Iterating over a list - Pseudocode/Python-like):

fruits = ["apple", "banana", "cherry"]

FOR EACH fruit IN fruits DO

  PRINT "I like " + fruit

END FOR

While Loops

While loops repeat a block of code as long as a specified condition remains true. The condition is checked before each iteration. If the condition is initially false, the loop may not execute at all.

Example (Pseudocode):

count = 0

WHILE count < 3 DO

  PRINT "Count is: " + count

  SET count = count + 1

END WHILE

It's important to ensure that the condition in a while loop will eventually become false; otherwise, it will result in an infinite loop!

Nested Control Structures

Control structures can be nested, meaning you can place one control structure inside another. For example, you might have an IF statement inside a FOR loop, or a FOR loop inside another FOR loop.

Conceptual Example (Iterating through a 2D grid):

Imagine you have a grid of squares, like a chessboard (e.g., rows = 8, cols = 8).

FOR r FROM 1 TO rows DO

  FOR c FROM 1 TO cols DO

    PRINT "Processing square at row " + r + ", col " + c

  END FOR

END FOR

In this case, the outer loop iterates through each row, and for each row, the inner loop iterates through each column. Nesting allows for more complex logic and handling of multi-dimensional data or scenarios.

Another example could be checking a condition for each item in a list:

numbers = [10, 25, -5, 40]

FOR EACH num IN numbers DO

  IF num > 0 THEN

    PRINT num + " is positive."

  ELSE IF num < 0 THEN

    PRINT num + " is negative."

  ELSE

    PRINT num + " is zero."

  END IF

END FOR
