What are Variables?

In programming, a variable is a symbolic name or identifier that refers to a storage location in the computer's memory. You can think of a variable as a labeled box where you can store and retrieve data that your program needs to work with. The data stored in a variable can be changed during the execution of a program, which is why they are called "variables."

Variables are fundamental because they allow us to write flexible programs. Instead of writing a program that only works with fixed values, we can use variables to represent data that might change each time the program runs or as the program is running.

Declaring Variables

Declaring a variable is the process of creating it. When you declare a variable, you typically give it a name and specify the type of data it will hold (though this varies by programming language).

In some languages, like Java or C++, you must explicitly declare the data type of the variable (e.g., int for integer, String for text). This is called static typing.

Example (Java-like):

int userAge;

String userName;

In other languages, like Python or JavaScript, the data type is often inferred from the value assigned to the variable. This is called dynamic typing.

Example (Python-like):

userAge = 30 // userAge is inferred to be an integer

userName = "Bob" // userName is inferred to be a string

Assigning Values

Assigning a value to a variable means storing a piece of data in the memory location that the variable refers to. This is typically done using an assignment operator, which is often the equals sign (=).

Example:

// Declaration (in a dynamically typed language) and assignment

score = 100;

// Assignment to an already declared variable

score = score + 10; // The variable 'score' now holds 110

The value on the right side of the = is evaluated, and the result is stored in the variable on the left side.

Naming Conventions

Choosing good names for variables makes your code much easier to read and understand. Here are some common best practices:

  • Be Descriptive: Names should indicate the purpose or content of the variable (e.g., customerName is better than cn).
  • Case Sensitivity: Most programming languages are case-sensitive, meaning myVariable and myvariable are different.
  • Start with a Letter or Underscore: Variable names typically cannot start with a number.
  • No Spaces: Variable names cannot contain spaces.
  • Common Styles:
    • camelCase: Start with a lowercase letter, and capitalize the first letter of each subsequent word (e.g., numberOfStudents). Common in JavaScript, Java.
    • snake_case: Use all lowercase letters, with words separated by underscores (e.g., number_of_students). Common in Python, Ruby.
    • PascalCase (or UpperCamelCase): Capitalize the first letter of every word (e.g., NumberOfStudents). Often used for class names.
  • Avoid Reserved Keywords: Do not use names that are keywords in the programming language (e.g., if, for, while).

Variable Scope (Basic Introduction)

Scope refers to the region of your program where a variable can be accessed. Not all variables are accessible from all parts of your program.

  • Local Variables: These are declared within a specific block of code, like a function. They can only be used within that block. Once the block finishes executing, the local variables usually cease to exist.
  • Global Variables: These are declared outside of any specific block (e.g., outside all functions). They can often be accessed from anywhere in the program. However, overuse of global variables can make programs harder to manage and debug.

Understanding scope helps prevent naming conflicts and manages memory effectively.

Examples (Pseudocode/Python-like)

Declaration and Assignment:

In some languages, you might see explicit declaration and assignment like this (pseudocode):

DECLARE age AS INTEGER

SET age = 30

More commonly in languages like Python, it's simpler:

age = 30

userName = "Alice"

temperature = 25.5

isActive = true // or True in Python

Using Variables:

Once variables have values, you can use them in expressions and statements:

PRINT "User's name is: " + userName

newAge = age + 1

PRINT "Next year, user will be: " + newAge

IF isActive THEN PRINT userName + " is currently active."
